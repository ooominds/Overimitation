# Overimitation

<br>

This repository contains the code for the analyses reported in:

> Divjak, D., Mackiewicz, J., & Milin, P. (2026). *Repeat after Me? Mapping the Relation of Overimitation to Foreign-Language Learning Aptitude*. To appear in *Slovo. Journal of Slavic Languages, Literatures and Cultures*, *66*(1). [https://doi.org/10.33063/slovo.v66i1.1242](https://doi.org/10.33063/slovo.v66i1.1242)

### Contents

- `01_BasicAnalyses.R` — Basic descriptive and inferential statistical analyses.
- `02_PCAs.R` — Principal component analyses used to obtain participants' scores on the extracted principal components.
- `03_GraphicalModelling.R` — Graphical modelling and invariant predictions analyses.
- `pca_scores.rda` — Participants' principal component scores saved as an R Data Archive (`*.rda`).

### Summary

Data were collected in two testing sessions scheduled one week apart, during which participants completed a battery of imitation, language, and cognitive tasks, as well as questionnaires. A total of 42 native speakers of Arabic (29 female), resident in the UK, took part in the study. The materials and experimental design were developed to test whether overimitation constitutes a previously unrecognised component of second-language aptitude.
